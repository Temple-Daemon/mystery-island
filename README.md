# 🏝️ MYSTERY ISLAND: THE LOST LIGHTHOUSE 🔦

### 🌊 An adventure of mystery, survival, puzzles and impossible decisions!

---

## 📖 About The Game

Stranded on a mysterious island after a violent storm, your mission is to restore the lighthouse beacon and secure your escape. 🚢

Explore mysterious locations, collect useful objects, solve puzzles and make critical decisions. But beware! Your energy is limited, and every move counts.

**Will you escape Mystery Island? Or will the island keep you forever?** 🌴

---

## 🎮 Game Features

- 🗺️ Explore five unique island locations.
- 🎒 Collect and manage useful items.
- 🧩 Solve puzzles and overcome obstacles.
- ⚖️ Make meaningful decisions with consequences.
- 🔋 Manage limited energy.
- 🌉 Unlock the Old Bridge using required items.
- 🔦 Restore the lighthouse beacon.
- 🏆 Experience victory or defeat.
- 🔄 Replay the adventure.

---

## 🎯 Your Mission

1. 🔍 Explore Mystery Island.
2. 🎒 Find and collect useful objects.
3. 🧩 Solve puzzles.
4. ⚖️ Make wise decisions.
5. 🔋 Preserve your energy.
6. 🌉 Find a way across the Old Bridge.
7. 🔦 Restore the lighthouse beacon.
8. 🚢 Secure your escape!

**Remember:** Running out of energy before completing your mission means game over!

## 🚀 Getting Started

### Requirements
- Python 3
- Git

### Installation

```bash
git clone https://github.com/Temple-Daemon/mystery-island.git
cd mystery-island
python main.py
```

### 🧪 Run Tests

```bash
python -m unittest discover -s tests -v
```
